# 다음 단계: 내 GitHub 계정에 홈페이지 올리고 키우기

빌더로 홈페이지 파일(`index.html`)을 만들었다면, 이 문서를 따라 **내 GitHub 계정**에 올리고 나중에 Cloudflare 나 Supabase 를 붙일 수 있습니다.
가입은 모두 여러분이 직접 해야 합니다. 이 프로그램은 대신 가입해 주지 않습니다.

## 0. 준비물

| 준비물 | 어디서 | 비용 |
| --- | --- | --- |
| 빌더에서 받은 `index.html` | 빌더의 **📄 홈페이지 파일 받기** | 무료 |
| GitHub 계정 | github.com 에서 **Sign up** | 무료 |
| (나중에) Cloudflare 계정 | cloudflare.com 에서 가입 | 무료 범위가 있음 |
| (나중에) Supabase 계정 | supabase.com 에서 가입 | 무료 범위가 있음 |

## 처음부터 끝까지 (코드 없이, AI 없이)

이 순서대로 하면 됩니다. 각 단계의 버튼 이름은 화면에 적힌 글자와 같습니다.

**1단계. 빌더 열기**
- 주소 `https://sunnykim717.github.io/claude-project/builder/` 를 엽니다.
- 왼쪽 질문에 한 번에 하나씩 답합니다. 건너뛰어도 됩니다.

**2단계. 기본 구성 채우기 (선택)**
- 질문이 어려우면 **기본 구성 채우기** 버튼을 누릅니다. 소개, 사업, 소식 같은 칸이 채워집니다.
- `[ ]` 안의 안내 글을 실제 내용으로 바꿉니다. 안내 글이 남아 있으면 빨간 경고가 나옵니다.

**3단계. 사진 넣기 (선택)**
- 로고, 대표 사진, 첫 화면 배경, 사진첩 칸에서 컴퓨터의 사진을 고릅니다. 사진은 자동으로 작아집니다.

**4단계. 미리 보기**
- 오른쪽 화면을 보고, **새 창에서 크게 보기** 버튼으로 완성된 모습을 확인합니다.

**5단계. 파일 받기와 저장하기**
- **📄 홈페이지 파일 받기**를 누르면 `index.html` 파일이 내려받아집니다.
- **💾 작업 저장**을 누르면 나중에 고칠 수 있는 파일이 내려받아집니다. 두 파일을 모두 보관하세요.

**6단계. GitHub에 올리기 (GitHub 계정이 필요합니다)**
- 빌더의 **GitHub에 올리기 도우미** 칸에 아이디와 저장소 이름을 적습니다.
- 아래 세 가지를 순서대로 합니다. 6단계 안의 번호는 ①②③ 로 씁니다.
  - **①** 저장소 만들기 → **②** 파일 올리기 → **③** 주소 켜기
- 각 번호를 끝내면 칸에 체크합니다.

**7단계. 주소 확인**
- 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 을 엽니다. 홈페이지가 보이면 끝입니다.

**고칠 때**
- **📂 작업 불러오기**로 저장해 둔 파일을 열고 고칩니다. 그다음 5단계와 6단계를 다시 하면 됩니다.

> 아래의 Cloudflare, Supabase 는 나중에 필요할 때만 보는 선택 사항입니다. 처음에는 읽지 않아도 됩니다.

## 자세한 설명

> 화면의 버튼 이름은 GitHub가 바꿀 수 있습니다. 적힌 이름이 조금 다르면, 같은 뜻의 버튼을 고르세요. 이 문서의 설명은 **Public(공개) 저장소**를 기준으로 합니다. GitHub Pages는 공개 저장소에서 무료로 쓸 수 있습니다.

## 자세한 설명: 1. GitHub 계정 만들기 (처음 한 번만)

1. `github.com` 에 들어가 **Sign up** 을 누릅니다.
2. 이메일, 비밀번호, 사용자 이름을 정합니다. 사용자 이름은 나중에 주소에 들어갑니다. 예: `github.com/내이름`
3. 이메일로 온 인증 코드를 입력하면 끝입니다.

## 2. 새 저장소(폴더) 만들기

저장소는 GitHub 안의 폴더라고 생각하면 됩니다.

1. 로그인한 뒤 오른쪽 위 **+** 를 누르고 **New repository** 를 고릅니다.
2. **Repository name** 에 `내-홈페이지` 처럼 영문이나 숫자로 적습니다.
3. **Public** 을 고릅니다. 공개해야 무료 홈페이지 주소가 생깁니다.
4. **Add a README file** 은 체크하지 않아도 됩니다.
5. **Create repository** 를 누릅니다.

## 3. 홈페이지 파일 올리기

1. 새로 만든 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
2. 빌더에서 받은 `index.html` 파일을 화면에 끌어다 놓습니다.
3. 아래 **Commit changes** 버튼을 누릅니다.

## 4. 무료 홈페이지 주소 켜기 (GitHub Pages)

1. 저장소 위쪽 탭에서 **Settings** 를 누릅니다.
2. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
3. **Build and deployment** 의 **Source** 를 **Deploy from a branch** 로 고릅니다.
4. **Branch** 는 `main`, 폴더는 `/ (root)` 를 고르고 **Save** 를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다.
   예: `https://내이름.github.io/내-홈페이지/`

고친 내용을 다시 올리려면 `index.html` 을 같은 방식으로 다시 올리면 됩니다. 기존 파일을 덮어쓰겠느냐는 질문에는 **Commit changes** 를 누르세요.

## 4-1. 사진첩은 나중에 늘릴 수 있습니다

지금 사진첩에는 **최대 12장**까지 넣을 수 있습니다.
- 더 넣고 싶으면 필요 없는 사진을 **빼기** 버튼으로 빼고, 새 사진을 넣으면 됩니다.
- 12장보다 많이 넣는 것은 빌더 프로그램 자체를 바꿔야 해서, 프로그램을 관리하는 사람에게 부탁해야 합니다.

## 나중에: Cloudflare Pages 로 옮기기 (선택)

Cloudflare 는 빠르고 나중에 사용자 정의 도메인을 붙이기 쉽습니다.

1. cloudflare.com 에 가입하고 대시보드에서 **Workers & Pages → Create → Pages → Connect to Git** 을 누릅니다.
2. GitHub 계정을 연결하고 `내-홈페이지` 저장소를 고릅니다.
3. **Build command** 는 비워 두고, **Build output directory** 는 `/` 로 둡니다. 정적 파일이라 빌드가 필요 없습니다.
4. **Save and Deploy** 를 누르면 `https://프로젝트이름.pages.dev` 주소가 생깁니다.

> GitHub Pages 와 Cloudflare 를 같은 저장소로 동시에 쓰면 둘 다 같은 파일을 보여 주므로 혼란이 적습니다. 한 가지만 골라도 됩니다.

## 나중에: Supabase 로 게시판과 로그인 붙이기 (선택, SQL 이 나옵니다)

방문자가 글을 올리고 관리자가 승인하는 기능입니다. 자세한 순서는 `website-template/docs/연결-가이드.md` 에 있습니다.

요약하면 다음과 같습니다.
1. supabase.com 에서 새 프로젝트를 만듭니다.
2. **SQL Editor** 에 `website-template/docs/supabase-board.sql` 내용을 붙여 넣고 실행합니다.
3. **Authentication → Providers → Email** 에서 공개 가입을 끕니다. 아무나 관리자가 되지 않게 하기 위해서입니다.
4. 프로젝트 주소와 **anon public** 키를 빌더나 편집기의 **Supabase 연결** 칸에 넣습니다.

> 비밀 키(`service_role`, `sb_secret_`)는 절대 저장소나 빌더에 넣지 마세요.

## 7. 확인할 것

- [ ] 홈페이지 주소가 열린다.
- [ ] 모바일에서도 글자가 잘린 곳 없이 보인다.
- [ ] 개인정보(주민번호, 계좌, 연락처 등)가 공개 페이지에 없다.
- [ ] 고칠 때마다 `index.html` 을 다시 올리고 주소를 새로고침해 본다.

## 8. 자주 생기는 문제

| 증상 | 해결 |
| --- | --- |
| 주소가 404 로 나옴 | Settings → Pages 에서 Branch 가 `main` 인지 확인하고 1~2분 기다립니다. |
| 고쳤는데 옛날 화면이 보임 | 강력 새로고침(`Ctrl + F5`) 또는 시크릿 창으로 엽니다. |
| Pages 설정 화면에 Upgrade 안내가 나옴 | 저장소가 비공개입니다. Settings → General 맨 아래에서 **Change visibility → Make public** 을 누릅니다. |
| Supabase 글쓰기에서 permission denied | `supabase-board.sql` 을 다시 실행했는지 확인합니다. |
