# 계정 없이 만들 수 있는 홈페이지의 범위

이 프로그램의 목표는 **계정 없이 홈페이지를 만들고 고치는 것**입니다. 이 문서는 그 목표에서 어디까지가 "계정 없이 되는 것"인지, 그리고 어디서부터 계정이나 서버가 필요한지 정합니다.

## 한 줄 정의

> **계정 없이는 "완성된 홈페이지 파일"까지 만듭니다.** 그 파일을 공개 주소에 올리는 일(호스팅)과 방문자가 쓰는 기능(글쓰기, 로그인)은 계정이나 서버가 필요합니다.

계정 없이 얻는 결과물은 `zip` 한 개입니다. 압축을 풀면 `dist/index.html` 을 더블클릭해 바로 열 수 있고, USB나 메신저로 옮길 수 있습니다.

## 1. 계정 없이 되는 것

| 영역 | 할 수 있는 것 | 어디에서 |
| --- | --- | --- |
| 기관 정보 | 이름, 설명, 언어, 로고 (사진 1장) | 편집기 글 쓰기, `site` |
| 글 | 17개 페이지의 제목·본문. 줄 바꿈 포함 | 편집기 글 쓰기 |
| 목록 | 사업, 소식, 연혁, 행사, 활동 이야기, 자료, 질문과 답, 게시판 글. 추가와 빼기 | 편집기 글 쓰기 |
| 사진 | 로고 1장, 배경 1장, 페이지마다 대표 사진 1장 | 편집기 사진 올리기 |
| 갤러리 | 페이지마다 사진 최대 12장 | 편집기 갤러리 |
| 디자인 | 색 조합 25가지, 글꼴 9가지, 여백 5단계, 배치 6가지, 메뉴 모양 4가지 | 편집기 디자인 고르기 |
| 메뉴 | 메뉴 추가와 삭제, 순서 바꾸기 | `add-menu`, `remove-menu` |
| 첫 화면 | 보일 칸과 순서 (소개, 사업, 소식) | `home.sections` |
| 직접 CSS | 모든 페이지 맨 뒤에 붙는 CSS (바깥 파일 호출 금지) | 편집기 직접 쓰는 CSS |
| 게시판 | 글 목록, 글마다 본문 펼쳐 보기 (내용은 관리자가 미리 씀) | 게시판 페이지 |
| 검사 | 설정과 내용이 맞는지 확인, 틀리면 저장하지 않음 | 편집기 검사, `check` |
| 미리보기 | 17개 페이지를 모두 골라 보기 | 편집기 보기 페이지 |
| 저장과 받기 | 설정 파일 저장·불러오기, 저장소 폴더 불러오기, zip 받기 | 편집기 |

## 2. 계정이 있어야 되는 것

| 기능 | 필요한 계정 | 비고 |
| --- | --- | --- |
| 공개 주소로 보이기 | GitHub (Pages) 또는 Cloudflare Pages | 파일만으로는 주소가 생기지 않음 |
| 저장소에 올리고 자동 배포 | GitHub | `website-template/docs/연결-가이드.md` 참고 |
| 방문자 글쓰기, 승인, 관리자 로그인 | Supabase | 서버 기능이므로 정적 페이지만으로는 불가 |
| 내 도메인 연결 | 도메인 등록 기관, Cloudflare 또는 GitHub | 도메인 비용은 별도 |

## 3. 할 수 없는 것 (계정이 있어도 이 프로그램의 범위 밖)

- 방문자가 사진이나 파일을 올리는 기능 (서버 저장소가 필요)
- 회원 가입, 결제, 예약, 신청서 저장 (서버 기능)
- 이메일 자동 발송, 댓글, 실시간 채팅
- 검색 기능 (정적 페이지는 전체 검색을 제공하지 않음)
- PDF 첨부 파일 (현재 자료실은 링크만 지원)
- 페이지 종류 추가 (17개 고정. 새 종류는 코드 추가가 필요함)
- 말로 요청하면 저장소를 고쳐 주는 기능 (Claude 계정이 필요한 별도 기능)
- 정해진 시간에 자동으로 고치거나 다시 만드는 일 (올릴 때만 배포가 실행됨)

## 4. 수치 한계

| 항목 | 한계 | 근거 |
| --- | --- | --- |
| 페이지 수 | 17개 (첫 화면 포함) | `schema.json` 의 `pages` |
| 페이지 대표 사진 | 페이지마다 1장, 15개 페이지 + 첫 화면 | `photo_pages` |
| 갤러리 | 페이지마다 12장 | `gallery_max` |
| 사진 원본 | 한 장 10MB 이하 | 편집기 업로드 검사 |
| 사진 저장 크기 | 가로 1200px 이하 JPEG로 줄여 저장 | 편집기 `shrinkPhoto` |
| 브라우저 저장 공간 | 사진이 많으면 저장이 실패함 (브라우저마다 다르며 수 MB 수준) | 실패 시 "설정 저장 (파일)" 안내 |
| 게시판 글 (Supabase 사용 시) | 제목 100자, 본문 2000자, 작성자 30자 | `supabase-board.sql` |
| 저장소 파일 크기 | GitHub 정책을 따름 (큰 파일은 저장소를 느리게 함) | 사진은 줄여서 저장되므로 보통 문제 없음 |

> 수치는 현재 코드 기준입니다. 브라우저 저장 공간처럼 환경마다 다른 값은 대략적으로만 적었습니다.

## 5. 이 범위에 맞춘 구성

- 편집기 맨 위에 **계정 없이 할 수 있는 범위**를 가리키는 안내를 둡니다.
- 공개, 자동 배포, 게시판 저장 같이 계정이 필요한 기능은 **연결 가이드**로 분리합니다.
- 범위를 넘는 요청(예: 방문자 사진 업로드)은 편집기에서 할 수 없다고 명확히 안내합니다.
- 이 문서의 수치가 바뀌면 `schema.json` 과 편집기 코드를 먼저 고치고, 이 문서를 맞춥니다.
