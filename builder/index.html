바이브 홈페이지 빌더

이렇게 쓰세요
  1. 왼쪽 질문에 답하면 오른쪽에 홈페이지가 바로 그려집니다.
  2. 다 됐으면 📄 홈페이지 파일 받기 를 누르세요. 받은 파일을 더블클릭하면 브라우저에서 열립니다.
  3. 내일 이어서 하려면 💾 작업 저장 으로 파일을 받아 두세요. 다시 열 때는 📂 작업 불러오기 로 그 파일을 고릅니다.

누르면 소개, 사업, 소식, 후원, 자원봉사, 오시는 길, 질문, 연락처 칸이 한 번에 채워집니다. [ ] 안의 글을 바꿔 쓰세요.

다음 단계: 내 GitHub 계정에 올리고 키우는 방법은 안내서 보기 를 누르세요.

질문에 답하면 홈페이지가 만들어집니다. 더 세밀하게 고치려면 아래 "직접 고치기"를 여세요.

질문에 답하며 만들기

질문에 하나씩 답하면 됩니다. 건너뛰어도 되고, 아래 칸에서 나중에 고칠 수 있습니다.

사진첩 (사진 여러 장)

사진은 자동으로 작게 줄여서 들어갑니다. 한 번에 여러 장을 고를 수 있습니다. 지금은 최대 12장이며, 나중에 더 늘릴 수 있습니다.

GitHub에 올리기 도우미 (선택)

GitHub 계정이 있을 때만 필요합니다. 아이디와 비밀번호는 이 화면에 적지 않습니다. 아래 단계 버튼을 차례로 누르세요.

직접 고치기 (고급)
말로 적기 (한 줄씩 적기)

한 줄에 하나씩 적으면 아래 칸이 채워집니다. 입력한 내용은 이 브라우저 안에서만 처리되고, 어디로도 보내지 않습니다.

붙여넣기 · 링크로 열기

명세(JSON)나 말로 적은 글을 붙여넣으면 적용합니다. 지금 내용을 링크로 복사해 두면 그 링크를 열 때 같은 내용이 채워집니다.

사이트 이름과 소개

도형으로 그림 만들기 (내 그림)

도형을 더해서 위치(x, y), 크기, 색을 정하세요. 0~100 사이 숫자입니다. 다 만들면 위의 장식 그림에서 "내 그림"을 고르세요.

디자인 (색, 글꼴, 모양)
기본 템플릿 고치기

기본 템플릿 하나를 골라 색과 글꼴을 바꿀 수 있습니다. 이 브라우저에만 저장되며, "기본값으로 되돌리기"로 원래대로 돌아갑니다.

내 템플릿은 이 브라우저에만 저장됩니다. 다른 컴퓨터에서 쓰려면 작업 저장 파일에 디자인이 함께 들어 있으니 그 파일을 쓰세요.

섹션 순서와 표시

체크하면 표시되고, ▲▼ 로 위아래 순서를 바꿉니다.

섹션 제목과 내용 (고급)

소식과 자주 묻는 질문은 말로 적기 칸에 한 줄씩 추가합니다. 예: 소식 추가: 행사 안내 | 2026-11-03 | 주민을 초대합니다 | https://example.com 과 질문: 이용료는 얼마인가요? | 무료입니다.

소식과 사업 목록
소식 목록 (자세한 내용과 사진 포함)

소식은 날짜가 빠른 순이 아니라 최신 순으로 보입니다. "자세한 내용"을 적으면 제목을 눌러 펼쳐 볼 수 있습니다.
