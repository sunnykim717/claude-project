# 바이브 코딩 명세 도구

명세(JSON)를 채우면 **실제로 동작하는 `index.html` 을 자동으로 만들어 줍니다.** AI 채팅이나 계정이 필요 없습니다.

## 흐름

1. `vibe/examples/visit_form.json` 을 복사해서 내 이름으로 저장합니다. (예: `my_spec.json`)
2. 칸을 내 내용으로 바꿉니다. 아래 "칸 설명"을 보세요.
3. 명령을 실행합니다.

   ```bash
   python vibe/build_app.py my_spec.json --out 결과/index.html
   ```

4. 명세에 빠지거나 잘못된 내용이 있으면 `명세를 고쳐 주세요:` 와 함께 목록이 나옵니다. 고친 뒤 3번을 다시 실행하세요.
5. 결과 `index.html` 을 브라우저로 엽니다.
6. 명세의 **완료 기준**을 하나씩 확인합니다.

예시 결과: [`vibe/examples/visit_form.html`](examples/visit_form.html) 을 브라우저로 열어 보세요.

## 칸 설명

| 칸 | 무엇을 적나요? | 예 |
| --- | --- | --- |
| `name` | 만들 것의 이름 (페이지 제목이 됩니다) | "방문 신청 페이지" |
| `goal` | 무엇을 하는 페이지인지 한두 문장 | "방문 날짜를 신청받는 페이지" |
| `users` | 누가 쓰는지 (목록, 안내용) | ["방문자", "담당자"] |
| `pages` | 화면 목록. 입력칸이 있는 화면은 순서대로 단계가 되고, 입력칸이 없는 화면은 **마지막에 하나만** 완료 화면이 됩니다 | 기본 정보, 수업 선택, 신청 완료 |
| `save` | `true` 이면 제출 내용을 이 기기에 저장하고 목록과 CSV 내려받기를 보여 줍니다 (기본값 `false`) | `true` |
| `fields` | 입력칸 (아래 표) | 이름(text, 필수) |
| `rules` | 지켜야 할 규칙 (화면 안내로 보입니다) | "인원은 1~20명" |
| `done` | 끝났다고 판단할 기준 (확인용, 한 개 이상) | "필수 입력을 비우면 안내가 나온다" |

### 입력칸 설정

| 설정 | 쓸 수 있는 곳 | 뜻 |
| --- | --- | --- |
| `label` | 모든 칸 | 화면에 보이는 이름 |
| `type` | 모든 칸 | `text`, `textarea`, `email`, `phone`, `date`, `number`, `select`, `radio`, `checkbox`, `url`, `time` 중 하나 |
| `required` | 모든 칸 | `true` 면 비우면 안 됩니다 |
| `options` | `select`, `radio` | 선택지 목록. 예: ["상담", "견학"] (`checkbox` 에는 쓸 수 없습니다) |
| `min`, `max` | `number` | 최소 값, 최대 값 (자동 검사) |
| `minLength`, `maxLength` | `text`, `textarea`, `email`, `phone`, `url` | 최소·최대 글자 수 (자동 검사) |
| `minToday` | `date` | `true` 면 오늘보다 이전 날짜를 막습니다 (자동 검사) |

`email` 과 `phone`, `date` 는 형식이 맞는지 자동으로 검사합니다.

## 자동으로 되는 것

- 입력 화면: 필수 입력, 형식, 최소·최대, 과거 날짜 금지를 검사하고, 틀린 칸에 안내 문구를 보여 줍니다.
- 단계: 입력 화면이 여러 개면 단계별로 검사하고, 이전·다음으로 오갈 수 있습니다.
- 완료 화면: 제출하면 입력 내용을 요약해서 보여 줍니다. 완료 화면의 이름이 제목이 됩니다.
- 다시 입력: 완료 화면에서 입력을 지우고 처음부터 다시 쓸 수 있습니다.
- 외부 요청 없음: 만들어진 파일은 외부 라이브러리나 서버를 쓰지 않고, 입력한 내용을 어디로도 보내지 않습니다.
- 한국어 문구와 글자 대비, 휴대폰 화면 대응

## 막아 주는 것

- 이름, 목적, 화면, 완료 기준이 비어 있으면 알려 줍니다.
- 허용되지 않은 입력칸 종류, 선택 목록의 선택지 누락을 알려 줍니다.
- `min`, `max` 를 number 가 아닌 칸에 쓰거나, `min` 이 `max` 보다 큰 경우를 알려 줍니다.
- 주민등록번호, 계좌번호, 카드번호, 비밀번호 같은 민감한 정보를 입력칸으로 만들지 않습니다.

## 한계와 해결 방법

| 한계 | 지금 상태 | 해결 방법 |
| --- | --- | --- |
| `rules` 가 자유 문장이라 검사되지 않음 | 입력칸 설정으로만 검사 (`required`, 형식, `min`, `max`, `minToday`, `minLength`, `maxLength`) | 규칙을 입력칸 설정으로 바꿔 적으세요. 생성할 때 규칙 목록을 함께 보여 줍니다. |
| 화면 수 | 입력 화면은 여러 단계로 가능, 완료 화면은 하나 | 완료 화면을 마지막에 하나만 두세요. |
| 저장 | `save: true` 이면 이 기기의 브라우저에 저장, CSV 로 내려받기 가능 | 여러 기기의 기록을 모으려면 서버가 필요합니다. 이 도구는 서버를 두지 않으므로, 기록은 CSV 로 내려받아 모읍니다. |
| 입력칸 종류 | text, textarea, email, phone, date, number, select, radio, checkbox, url, time | 여기에 없는 입력칸은 AI 요청문(`make_brief.py`)으로 만드세요. |
| GitHub 링크 | 짧은 페이지만 링크로 열림 (코드 길이 제한) | 긴 페이지는 "index.html 로 내려받기" 후 GitHub 의 "파일 추가 → 파일 업로드"로 올리세요. |
| GitHub 에 올리기 | GitHub 로그인이 필요합니다 | 계정 없이는 내려받은 `index.html` 을 직접 열거나 원하는 곳에 올리세요. |

### 저장과 개인정보

- 저장 내용은 **이 기기의 브라우저에만** 있습니다. 브라우저의 사이트 데이터를 지우면 함께 사라집니다.
- 신청자의 정보가 들어가므로, CSV 를 받은 뒤에는 필요한 사람에게만 전달하고 보관 기간을 정해 두세요.
- 주민등록번호, 계좌번호 같은 민감한 정보는 입력칸으로 만들 수 없습니다.


## AI 로 더 다듬고 싶을 때

`python vibe/make_brief.py 명세.json --out brief.md` 를 실행하면 같은 명세로 AI 에 붙여 넣을 요청문을 만듭니다. 생성된 페이지를 AI 로 고치거나, 이 도구로 할 수 없는 화면을 만들 때 쓰세요. 이 경우에는 그 AI 서비스의 계정을 사용합니다.
