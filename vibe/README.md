# 바이브 코딩 명세 도구

"이런 프로그램을 만들고 싶어요"라고 막연하게 말하면 AI 가 자꾸 다른 것을 만듭니다. 이 도구는 생각을 **정해진 칸에 채우게** 해서, 빠진 내용을 먼저 찾아내고 AI 에 그대로 줄 수 있는 요청문을 만듭니다. 설치나 계정이 필요 없습니다.

## 흐름

1. `vibe/examples/visit_form.json` 을 복사해서 내 이름으로 저장합니다. (예: `my_spec.json`)
2. 칸을 내 내용으로 바꿉니다. 아래 "칸 설명"을 보세요.
3. 명령을 실행합니다.

   ```bash
   python vibe/make_brief.py my_spec.json --out brief.md
   ```

4. 명세에 빠진 내용이 있으면 `명세를 고쳐 주세요:` 와 함께 목록이 나옵니다. 목록을 보고 고친 뒤 3번을 다시 실행하세요.
5. `brief.md` 파일을 열어 전체를 복사합니다.
6. 평소 쓰는 AI 채팅에 붙여 넣고 "이 요청대로 만들어 줘"라고 말합니다.
7. AI 가 만든 `index.html` 을 브라우저로 열어 **완료 기준** 체크리스트를 하나씩 확인합니다.

## 칸 설명

| 칸 | 무엇을 적나요? | 예 |
| --- | --- | --- |
| `name` | 만들 것의 이름 | "방문 신청 페이지" |
| `goal` | 무엇을 하는 프로그램인지 한두 문장 | "방문 날짜를 신청받는 페이지" |
| `users` | 누가 쓰는지 (목록) | ["방문자", "담당자"] |
| `pages` | 화면 목록. 각 화면에 `name` 과 `fields`(입력칸) | 신청 화면, 접수 완료 화면 |
| `fields` | 입력칸. `label`, `type`, `required`, 선택 목록이면 `options` | 이름(text, 필수) |
| `rules` | 지켜야 할 규칙 (목록) | "인원은 1~20명" |
| `done` | 끝났다고 판단할 기준 (목록, 한 개 이상) | "필수 입력을 비우면 안내가 나온다" |

입력칸 `type` 으로 쓸 수 있는 값: `text`, `textarea`, `email`, `phone`, `date`, `number`, `select`

## 이 도구가 막아 주는 것

- **빈칸**: 이름, 목적, 화면, 완료 기준이 비어 있으면 알려 줍니다.
- **잘못된 입력칸 종류**: 허용되지 않은 `type` 을 알려 줍니다.
- **선택 목록**: `select` 인데 선택지가 없으면 알려 줍니다.
- **민감한 개인정보**: 주민등록번호, 계좌번호, 카드번호, 비밀번호 같은 입력칸은 만들 수 없습니다.

## 요청문에 자동으로 들어가는 것

- 단일 `index.html` 파일, 외부 라이브러리 없음
- 한국어 문구
- 입력 형식은 브라우저에서 검사, 입력값은 서버로 보내지 않음
- 휴대폰 화면과 글자 대비 기준
- AI 가 명세에 없는 내용을 추측으로 채우지 말고 목록으로 알려 주도록 하는 지시

## 한계

- 이 도구는 명세를 **요청문으로 바꾸는 것까지**만 합니다. 실제 코드를 만드는 것은 AI 채팅이 합니다.
- 명세에 없는 기능은 만들어지지 않습니다. 필요하면 명세에 먼저 적으세요.
- 저장이 필요한 프로그램은 명세의 `rules` 에 저장 방식을 적어야 합니다. 저장 방식을 정하지 않으면 AI 가 목록으로 되물어야 합니다.
