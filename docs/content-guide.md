# 홈페이지 문장 작성 가이드

Claude Code 클라우드 세션이 `data/site.json`의 글을 쓰거나 고칠 때 따르는 규칙입니다.

## 수정 범위

- `data/site.json`의 텍스트 필드(`title`, `subtitle`, `about`, `contact`, `items[].summary`, `items[].tag` 등)만 고칩니다.
- `index.html`은 직접 고치지 않습니다. 생성기가 다시 만듭니다.
- 요청에 없는 항목은 바꾸지 않습니다.

## 사실 정보

- 날짜, 링크, 이메일, 연락처, 수치, 수상 이력 같은 사실은 **요청 문장이나 기존 데이터에 있는 것만** 씁니다.
- 요청에 없는 사실을 지어내지 않습니다. 부족한 정보가 있으면 빈 값으로 두고 보고합니다.
- 링크는 `https://` 로 시작하는 것만 사용합니다.

## 길이와 형식

| 필드 | 권장 길이 |
| --- | --- |
| `title` | 60자 이내 |
| `subtitle` | 60자 이내 |
| `items[].title` | 40자 이내 |
| `items[].summary` | 1–3문장, 150자 이내 |
| `about` | 500자 이내, 줄바꿈 가능 |
| `contact` | 한두 줄 |

## 문체

- 기본 언어는 한국어이고, 존댓말(`-습니다`, `-요`)로 씁니다.
- 과장된 표현("최고의", "혁신적인")은 피하고, 구체적으로 씁니다.
- 한 문장에 하나의 내용만 담습니다.

## 작업 절차

1. 요청을 읽고 바꿀 필드를 먼저 정합니다.
2. 해당 필드만 고칩니다.
3. `python -m unittest discover -s tests` 로 테스트를 통과하는지 확인합니다.
4. `python update_homepage.py` 로 `index.html`을 생성합니다.
5. 변경한 필드와 사실 정보 출처를 요약해 보고한 뒤 push합니다.

## 보고 형식

- 바꾼 필드: 필드 이름과 변경 전후를 짧게
- 확인이 필요한 사실: 요청에 없어서 비워 두거나 추측하지 않은 항목
- 검증 결과: 테스트와 생성 결과
